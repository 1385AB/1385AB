# Arshia — Personal website

A responsive personal page for [1385AB](https://github.com/1385AB), made with plain HTML and CSS. It shares the learning goals and public links from this profile without a build step or additional dependencies.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish with GitHub Pages

GitHub Pages is configured to deploy from the `1385ab-personal-website` branch and `/ (root)` folder. The site URL is <https://1385ab.github.io/1385AB/>.

## Personalize

Edit `index.html` to update the page text and social links. Edit `styles.css` to change the colors, typography, and layout.
